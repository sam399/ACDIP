# Database migrations

Run migrations from the repository root:

```powershell
python -m alembic upgrade head
python -m alembic current
python -m alembic check
```

SQLite migrations use Alembic batch mode. Review every autogenerated revision,
especially rename, copy, and drop operations, before applying it.

Current staged normalization:

- `0003_shelters` reconciles and removes redundant shelter columns.
- `0004_f14_expand` backfills normalized F14 assessment and override tables.
- Legacy F14 request columns remain temporarily for rollback-safe dual writes.
